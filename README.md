# Madu Lash Studio 

Site desenvolvido para o Madu Lash Studio, com foco na apresentação profissional do trabalho da lash designer Maria Eduarda.

O projeto possui um design elegante e responsivo, valorizando a identidade visual do estúdio e os resultados dos procedimentos.

# Funcionalidades

- Apresentação do Madu Lash Studio
- Seção sobre a profissional
- Apresentação das técnicas disponíveis
- Galeria de resultados
- Sistema "Ver mais / Ver menos" na galeria
- Botão para voltar ao topo da página
- Agendamento pelo WhatsApp
- Layout responsivo para diferentes tamanhos de tela

# Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
